# Atvweb2 - Flask

Projeto acadêmico fictício da equipe de esports Macacos Evoluídos, adaptado para Flask para a Atividade 3.

## Executar localmente

```bash
python -m venv venv
# Windows: venv\Scripts\activate
# Linux: source venv/bin/activate
pip install -r requirements.txt
python app.py
```

Acesse: `http://127.0.0.1:5000`

As imagens, jogadores, campeonatos e descrições do projeto são fictícios e foram criados para fins acadêmicos.
