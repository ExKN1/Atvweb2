# Atvweb

## Sobre o projeto

Este projeto apresenta um site fictício de uma equipe de **E-sports chamada Macacos Evoluídos**.

O site foi desenvolvido com foco nos jogos **VALORANT** e **League of Legends (LoL)**.

> **Observação:** As imagens e algumas das descrições do projeto foram feitas com ajuda de Inteligência Artificial. Os jogadores, campeonatos, resultados e demais informações da equipe são fictícios e foram criados apenas para o projeto.

## Estrutura do projeto

### 🏠 Página Home

A página inicial apresenta uma breve introdução sobre a equipe.

* Navbar responsiva utilizando **Bootstrap**.
* Seção **Hero** responsiva utilizando **Flexbox**.
* **Carousel** do Bootstrap para apresentar jogadores e vitórias da equipe.
* Layout adaptado para computadores e smartphones.

### 👥 Página Sobre

A página apresenta informações sobre a equipe e sua história.

* Uso das tags semânticas `<article>` e `<section>`.
* Seção com **5 motivos para apoiar a equipe**.
* Cards utilizando o sistema **Grid** do Bootstrap.
* Apresentação dos jogadores do plantel.

### 📩 Página Contato

A página possui um formulário simples para contato.

* Campos de e-mail, assunto e mensagem.
* Utilização de **Form Controls** e **Buttons** do Bootstrap.
* Botão **"Trabalhe Conosco"**.
* Modal do Bootstrap com informações sobre requisitos para novos jogadores.

## Requisitos técnicos

O projeto utiliza:

* **HTML5**
* **CSS3**
* **Bootstrap**
* **Flexbox**
* **Bootstrap Grid**
* **Bootstrap Carousel**
* **Bootstrap Cards**
* **Bootstrap Modal**

Também foram utilizadas tags semânticas como:

```html
<header>
<nav>
<section>
<article>
<footer>
```

A estrutura das páginas utiliza o componente **Container** do Bootstrap para organizar o conteúdo e garantir responsividade.

## Entrega

O projeto contém os arquivos necessários para o funcionamento do site, incluindo:

* Arquivos HTML
* Arquivos CSS
* Imagens utilizadas no projeto

O projeto foi desenvolvido para fins **acadêmicos** e todos os personagens, jogadores, equipes, campeonatos e resultados apresentados são fictícios.
